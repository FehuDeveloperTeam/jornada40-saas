# Anexo A. Glosario {.unnumbered #sec-anexo-a}

Términos, siglas y abreviaturas del documento, en orden alfabético. Incluye los de la sección 1.5.3. Las definiciones legales son las que usa el sistema y no reemplazan el texto de la norma.

#### Términos laborales y previsionales {.unnumbered}

| Término o sigla | Significado |
|---|---|
| AFC | Administradora de Fondos de Cesantía: administra el seguro de cesantía (Ley 19.728) |
| AFP | Administradora de Fondos de Pensiones (DL 3.500) |
| Amonestación | Carta con que el empleador deja constancia escrita de una falta del trabajador |
| Anexo de contrato | Documento que modifica el contrato vigente. En Jornada40, sus cambios pasan al contrato cuando se firma |
| Anexo de 40 horas | Anexo que adecua la jornada pactada a la máxima legal vigente (Ley 21.561) |
| Art. 22 | Trabajador excluido de la limitación de jornada (Art. 22 inc. 2° CT): su contrato no fija horario |
| Asignación familiar | Beneficio por cada carga familiar reconocida, cuyo monto depende del tramo de ingreso del trabajador; el empleador lo paga con la remuneración |
| Carta de término | Comunicación escrita del despido, con la causal, los hechos y el estado de las cotizaciones (Art. 162 CT) |
| Causal | Motivo legal de término del contrato (Arts. 159, 160 y 161 CT) |
| CCAF | Caja de Compensación de Asignación Familiar |
| Certificado N°6 | Certificado anual de sueldos y retenciones que el empleador entrega a cada trabajador, según las instrucciones del SII (Res. Ex. N° 6.509) |
| Conciliación | Peticiones de teletrabajo o de cambio de jornada de quien tiene a su cuidado a un niño o a una persona con discapacidad o dependencia (Ley 21.645) |
| Consentimiento electrónico | Aceptación del trabajador de recibir y firmar sus documentos laborales en forma electrónica (Dictamen 0789/15 de la DT) |
| Constancia | Documento que registra un hecho: un permiso legal, la entrega de EPP, la información de riesgos o la recepción del reglamento, entre otros |
| Cotización | Aporte a la seguridad social que se descuenta de la remuneración o que paga el empleador |
| CT | Código del Trabajo |
| Días corridos y días hábiles | Corridos son todos los días. Los hábiles dependen del tema: de lunes a viernes sin feriados para los plazos de Mi DT y de la Ley Karin; de lunes a viernes para el feriado (el sábado es inhábil, Art. 69 CT); de lunes a sábado para los permisos legales |
| DJ 1887 | Declaración jurada anual del empleador al SII sobre los sueldos pagados y los impuestos retenidos |
| DS | Decreto supremo |
| DT, Mi DT | Dirección del Trabajo; Mi DT es su sitio de trámites en línea para empleadores |
| Encargado de denuncias | Persona que el titular designa para recibir y gestionar las denuncias de la Ley Karin, con un acceso aislado |
| EPP | Elementos de protección personal, que el empleador entrega sin costo (Art. 68 de la Ley 16.744) |
| Expediente | Datos, plazos y documentos de una denuncia de la Ley Karin |
| FEA | Firma electrónica avanzada (Ley 19.799). Jornada40 usa firma electrónica simple |
| Feriado | Vacaciones anuales pagadas de 15 días hábiles (Art. 67 CT). El progresivo agrega días por los años trabajados (Art. 68); el proporcional se paga al término de la relación (Art. 73) |
| Ficha | Registro de un trabajador (`Empleado`) en una empresa. Quien trabaja en dos empresas tiene una ficha en cada una |
| Finiquito | Documento que pone término a la relación y detalla lo que se paga. Tiene poder liberatorio solo si se ratifica ante un ministro de fe o se otorga en Mi DT (Art. 177 CT) |
| Firma electrónica simple | La que no es avanzada (Ley 19.799). En Jornada40 combina la identidad verificada, la aceptación expresa y la firma dibujada (sección 8.9) |
| Fonasa, Isapre | Fondo Nacional de Salud; instituciones de salud previsional privadas |
| Fuero | Protección que impide despedir al trabajador sin autorización judicial previa (Art. 174 CT), por ejemplo por maternidad o por cargo sindical |
| Gratificación legal | Participación del trabajador en las utilidades: anual (Art. 47 CT) o mensual, con tope anual de 4,75 ingresos mínimos (Art. 50 CT) |
| Haber imponible, no imponible | Pagos que forman, o no, la base de cálculo de las cotizaciones |
| Horas extra | Horas sobre la jornada pactada, con un recargo mínimo del 50 % y un pacto escrito (Arts. 30 a 32 CT). Desde la Ley 21.561 pueden compensarse con días libres |
| IMM | Ingreso mínimo mensual |
| Impuesto único | Impuesto único de segunda categoría sobre las remuneraciones, que retiene el empleador |
| Indemnización a todo evento | Pacto del Art. 164 CT: desde los seis años de servicio, sustituye la indemnización por años de servicio por un aporte mensual del empleador |
| IPS | Instituto de Previsión Social |
| ISL, mutual | Organismos administradores del seguro de accidentes del trabajo (Ley 16.744): el Instituto de Seguridad Laboral, público, y las mutuales de seguridad (ACHS, Mutual de Seguridad CChC e IST) |
| Jornada máxima | Límite legal de horas semanales: 45, 44, 42 y 40 según la fecha (Ley 21.561) |
| Ley Karin | Ley 21.643, sobre acoso laboral, acoso sexual y violencia en el trabajo |
| Liquidación de sueldo | Documento mensual con los haberes, los descuentos y el líquido a pagar |
| LRE | Libro de Remuneraciones Electrónico, que se carga cada mes en Mi DT (Art. 62 bis CT) |
| Ministro de fe | Persona ante quien se ratifica un finiquito: inspector del trabajo, notario, oficial del Registro Civil o secretario municipal, entre otros (Art. 177 CT) |
| Modalidad | Forma de prestar los servicios: presencial, remota o híbrida |
| ORD | Oficio ordinario de la DT |
| Pacto | Acuerdo escrito entre empleador y trabajador, como el de horas extra, el de indemnización a todo evento o el de teletrabajo |
| Permiso legal | Días de permiso pagados que da la ley, por ejemplo por fallecimiento de un familiar, nacimiento o matrimonio (Arts. 66, 195 y 207 bis CT) |
| Poder liberatorio | Efecto del finiquito ratificado: el trabajador no puede reclamar después lo que en él se pagó |
| Previred | Plataforma de declaración y pago de las cotizaciones previsionales |
| Ratificación | Firma del finiquito ante un ministro de fe o en Mi DT. En la fiscalización, la constancia que el inspector agrega en terreno a un documento |
| Registro electrónico laboral | Obligación de registrar en Mi DT los contratos, los anexos y los términos de la relación laboral (Ley 21.327) |
| Represalia | Medida de la empresa contra quien denunció o declaró en un caso de la Ley Karin; el sistema la advierte solo al encargado |
| Resguardo | Medidas que protegen a la persona afectada mientras dura una investigación de la Ley Karin |
| RIOHS, RIHS | Reglamento Interno de Orden, Higiene y Seguridad (obligatorio con 10 o más trabajadores, Art. 153 CT); Reglamento Interno de Higiene y Seguridad (Ley 16.744) |
| RUT | Rol Único Tributario, identificador de personas y empresas en Chile |
| SANNA | Seguro para el acompañamiento de niños y niñas con una enfermedad grave (Ley 21.063) |
| Semana corrida | Pago de los domingos y festivos a quien gana por día o tiene remuneración variable (Art. 45 CT) |
| SII | Servicio de Impuestos Internos |
| SIS | Seguro de invalidez y sobrevivencia, que paga el empleador |
| SUSESO | Superintendencia de Seguridad Social |
| Teletrabajo | Trabajo a distancia regulado por la Ley 21.220; en Jornada40 se pacta con un anexo |
| Tope imponible | Monto máximo, en UF, sobre el que se calculan las cotizaciones |
| Tramo | Tramo de ingreso que fija el monto de la asignación familiar: A, B, C o D (sin derecho) |
| UF, UTM | Unidad de Fomento y Unidad Tributaria Mensual, unidades reajustables que se usan en topes y tramos |

#### Términos del sistema {.unnumbered}

| Término | Significado |
|---|---|
| Aviso | Advertencia de un posible incumplimiento normativo: informa, pero no impide continuar |
| Bitácora | Registro de las acciones del panel, encadenado con huellas para detectar alteraciones; se conserva al menos 5 años |
| Bolsa de horas | Horas de descanso ganadas con horas extra compensadas, calculadas desde las liquidaciones emitidas |
| Carpeta | Pantalla del panel que reúne los datos y documentos de un trabajador |
| Cerco | Control que limita a un usuario del equipo a sus módulos y a sus empresas (sección 8.3) |
| Ciclo | Periodicidad del pago del plan: mensual o anual |
| Concepto | Haber o descuento del catálogo de remuneraciones, con su naturaleza y su código del LRE |
| Cupo | Número máximo de trabajadores, empresas o usuarios que permite el plan |
| Empresa | Empleador registrado en una cuenta, identificado por su RUT |
| Folio | Número correlativo impreso en certificados, copias de la bitácora y denuncias |
| Mapeo | Correspondencia entre un dato de la ficha y un campo de un formulario de Mi DT, que usa la extensión |
| Módulo | Área del panel con permiso propio para el equipo, como Trabajadores, Contratos o Remuneraciones |
| Panel | Aplicación web del empleador, que usan el titular y su equipo |
| Parámetros previsionales | Topes, tasas e ingreso mínimo de cada período, que mantiene el equipo de Jornada40 |
| Petición | Solicitud del trabajador desde el portal: vacaciones, permiso o conciliación |
| Plan | Semilla, Starter, Pyme o Corporativo, con niveles 1 a 4 que habilitan las funciones |
| Portal del trabajador | Acceso de los trabajadores a sus documentos, certificados y peticiones |
| Portal de fiscalización | Acceso de solo lectura para los inspectores de la DT |
| Resumen por correo | Correo periódico al titular y al equipo con lo que requiere atención |
| Solicitud de firma | Registro del envío de un documento a firma, con su estado y su evidencia |
| Staging | Ambiente de pruebas, separado de producción, donde se valida cada versión antes de publicarla |
| Titular | Dueño de la cuenta, normalmente el empleador o su representante |
| Usuario del equipo | Persona que el titular invita, con acceso solo a los módulos y empresas que se le asignan |
| Verificación | Comprobación pública de un certificado o de una copia de la bitácora con el código impreso en él, en `/verificar` |

#### Términos técnicos {.unnumbered}

| Término o sigla | Significado |
|---|---|
| ADR | Registro de una decisión de arquitectura (sección 4.8) |
| API, REST | Interfaz de programación de aplicaciones; REST es el estilo de la API del servidor, sobre HTTP y JSON |
| B2 | Backblaze B2, almacenamiento de archivos compatible con S3 |
| C4 | Modelo de diagramas de arquitectura por niveles: contexto, contenedores y componentes |
| CORS | Mecanismo del navegador que define qué sitios pueden llamar a la API con credenciales |
| CSP | Política de seguridad de contenidos del navegador; aún no está configurada (sección 8.10) |
| CSRF | Falsificación de solicitudes entre sitios; la API la impide revisando el origen de las escrituras |
| DRF | Django REST Framework, biblioteca de la API |
| Fernet | Cifrado simétrico autenticado que protege los datos de la Ley Karin |
| HMAC | Código de autenticación de un mensaje con una clave; aquí, con SHA-256 |
| Huella | Resumen SHA-256 de un contenido, que cambia si el contenido cambia |
| Integración continua | Ejecución automática de las pruebas y revisiones en cada cambio (GitHub Actions) |
| JWT | JSON Web Token: credencial firmada de la sesión del panel, guardada en cookies |
| Middleware | Componente que procesa cada solicitud antes o después de la vista |
| Migración | Cambio versionado del esquema de la base de datos |
| MV3 | Manifest V3, formato actual de las extensiones de Chrome y Edge |
| OTP | Código de un solo uso enviado por correo para verificar la identidad |
| PBKDF2 | Algoritmo con que se guardan las contraseñas, con 1.000.000 de iteraciones |
| Recorrido de navegador | Prueba de extremo a extremo que usa la aplicación en Chromium (Playwright) |
| SameSite | Atributo de una cookie que limita su envío desde otros sitios |
| SPA | Aplicación de una sola página: la aplicación web carga una vez y cambia de pantalla sin recargar |
| Token | Credencial que identifica una sesión, un enlace o un dispositivo |
| WCAG | Pautas de accesibilidad web del W3C; el sistema revisa los niveles A y AA |
